Host Registration Process

  1. Login with email (Gmail)
  2. Fill in agency invitation code
  3. Read instructions & complete face verification
  4. Upload profile pictures (real photos required)
  5. Complete newbie tasks to unlock all features
  6. Start working and earning!

Withdrawal steps: Go to earnings page → Add payment account → Withdraw once daily→ Wait for 1-3 days to process
